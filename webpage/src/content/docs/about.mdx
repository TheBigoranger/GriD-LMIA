## The project

GriD-LMIA, the Gridding-based DPD-LMI Assembler, is an open-source
MATLAB/YALMIP package for parameter-dependent linear matrix inequalities. Its
focus is cell-wise Bernstein representations for
control and optimization models, including differentiable decisions and
finite certificate construction on gridded parameter domains.
