# `useSpBox`

`useSpBox` rebuilds an inequality from its stored `Residual` with SparseFullBox sliding tensor-window Gram blocks. It is a value-semantic selector and does not modify the source object.

## Syntax

```matlab
selected = C.useSpBox()
selected = C.useSpBox(windowSize)
selected = C.useSpBox(windowSize, order)
selected = C.useSpBox(..., ValidationMode=mode)
```

## Arguments And Options

| Input | Meaning |
| --- | --- |
| `windowSize` | Positive integer tensor-window side. Default `2`. |
| `order` | Nonnegative scalar or one entry per parameter axis. The default is the minimum admissible absolute order. |
| `ValidationMode` | Current supported transient validation mode. It changes validation work, not certificate meaning. |

## Returned Object

The returned `pdlmi` selects `UseSparseFullBoxPreorder`, `SparseFullBoxOrder`, and `BandWidth`. All other certificate-family flags are false. A window size of one normalizes to Direct. A window that spans every active basis axis normalizes to FullBox.

## Example

```matlab
yalmip('clear')
P = pdvar(2, {[0 0.5 1]}, "symmetric", Degree=2);
direct = P >= eye(2);
sparse = direct.useSpBox(2, 2);
F = sparse.toYalmip();
```

The selector creates fresh Gram variables for every entrywise copy when applicable, physical cell, rate row, and tensor window. Numeric coefficient maps may be reused.

## Anisotropic Assembly Output

For $\mathbf M=(4,2)$, $\mathbf r=(2,1)$, and `BandWidth=2`, the four
full-box generator subsets have basis degrees $(2,1)$, $(1,1)$, $(2,0)$,
and $(1,0)$. Their sliding-window diagrams contain $2+1+2+1=6$ independent
PSD blocks. The blocks contribute to one $5\times3$ tensor of 15 exact target
coefficient identities.

## Validation And Limitations

- Equality residuals reject every non-Direct selector.
- Window size and order must be finite nonnegative integers in the implemented ranges.
- A fixed order and window size give a sufficient certificate. Failure is inconclusive.
- The construction uses sliding windows in tensor-label space. It is not a band constraint on a flattened Gram matrix.

The full derivation, PSD dimensions, coefficient identities, and canonical endpoints are in [SparseFullBox And FullBox](/GriD-LMIA/documents/math/finite-certificates/sparsefullbox-and-fullbox/).
