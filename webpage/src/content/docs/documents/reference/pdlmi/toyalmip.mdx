## Purpose

Export stored `pdlmi` entries as a YALMIP constraint array or, for Direct and
Pólya known-data wrappers, one scalar logical certificate.

## Syntax

```matlab
F = toYalmip(C)
F = C.toYalmip()
```

## Arguments

| Argument | Description |
| :--- | :--- |
| `C` | A `pdlmi` object, such as `C = P >= 0`. |

## Output

For a `pdvar` residual, `F` is a YALMIP constraint array suitable for ordinary
solver calls, or `[]` when a direct equality is proven identically zero. For a
coefficient-backed known `pdmat` residual, Direct and Pólya return a scalar
logical.

## Description

`pdlmi` stores constraints in package-owned cell-local form. Direct and Pólya
objects store one sign condition per physical cell, Bernstein coefficient, and
rate vertex. Putinar, SparsePutinar, SparseFullBox, and FullBox objects instead store PSD Gram-block
conditions followed by exact coefficient identities for every cell and rate
row. `toYalmip` is the
boundary where the stored entries become a regular YALMIP constraint array:

$$
F = [F_1,\ldots,F_N].
$$

For direct and Pólya inequalities, $N$ is the number of physical cells times the
number of active rate rows times the number of assembled Bernstein
coefficients. For Putinar, SparsePutinar, SparseFullBox, and FullBox objects, $N$ instead counts every stored
PSD Gram condition and exact coefficient identity across those cells and rows.

The known-data logical test uses the wrapper’s single global inequality
classification and inclusive absolute tolerance `1e-10`. Semidefinite mode
symmetrizes each coefficient matrix and tests its eigenvalues; only
entry-wise mode tests individual scalar entries. A false result warns with
`pdlmi:InconclusiveCertificate` because failure of this sufficient coefficient
test does not prove a continuous violation or matrix indefiniteness.

Known-data Putinar, SparsePutinar, SparseFullBox, and FullBox wrappers still export YALMIP
constraints and may contain auxiliary Gram variables. `toYalmip` does not
choose a solver, create an objective, apply relaxation margins, or run
`optimize`.

For equality, direct coefficient groups are concatenated in MATLAB
column-major entry order. Proven zero groups are omitted; consequently
`toYalmip(P == P)` returns `[]`.

## Examples

### Function-call form

```matlab
yalmip('clear')
P = pdvar(2, {[0 1]}, "symmetric");
C = P >= 0;
F = toYalmip(C);
isa(F, "lmi") || isa(F, "constraint")
length(F)
```

```text
ans =
  logical
   1

ans =
     2
```

The two YALMIP entries correspond to one physical cell and two degree-one
Bernstein coefficients.

### Dot-call form

```matlab
yalmip('clear')
P = pdvar(2, {[0 1]}, "symmetric");
C = P >= 0;
F = C.toYalmip();
isa(F, "lmi") || isa(F, "constraint")
length(F)
```

```text
ans =
  logical
   1

ans =
     2
```

The dot-call form is equivalent and is convenient when chaining from a stored
`pdlmi` object.

### Empty identity equality

```matlab
yalmip('clear')
V = pdvar(3, 2, {[0 1]}, "full");
F = (V == V).toYalmip()
```

```text
F =
     []
```

`toYalmip` does not select solvers, add objectives, apply relaxation margins, or run `optimize`.

### Known-data logical export

```matlab
yalmip('clear')
A = pdmat([0 1], {{1, 2; 3, 4}}, ...
    Degree=1, RateBounds=[-1 2]);
direct = A >= 0;
directCertificate = toYalmip(direct)
polya = direct.applyPolya(1);
polyaCertificate = toYalmip(polya)
```

```text
directCertificate = logical
   1

polyaCertificate = logical
   1
```
