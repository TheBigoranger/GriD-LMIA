`pdlmi` stores finite YALMIP constraints generated from square `pdvar`
residual expressions. Direct coefficient assembly is the default; Pólya
degree elevation, fixed-order Putinar box assembly, and fixed-order full box
Bernstein-Gram preordering are explicit alternatives.

<CertificateDiagram kind="map" />

The four paths begin with the same stored residual. **Direct** tests every
local coefficient and is the default. **Pólya** exactly elevates that residual
before repeating the direct test. **Putinar** introduces an unweighted Gram
term and one generator-weighted term per parameter. **Full box** adds Gram
terms for every subset product of the generators. Both Gram paths match exact
box-polynomial identities. The
[SOS certificate chapter](/PD-LMI-package/documents/math/sos-certificates/)
derives these ideas; the API pages below stay focused on callable syntax.

## Current Boundary

Direct coefficient-wise assembly is the default. Pólya degree elevation is
available through constructor options and `applyPolya`. The opt-in Putinar
and full-box paths use independent positive-semidefinite Gram blocks for each
physical cell and active rate row, with exact coefficient identities. Putinar
uses only the axis generators $\alpha_s(1-\alpha_s)$ separately; full box
also uses every subset product. They are fixed-order certificates on the local
hypercube, not a general-domain SOS interface or automatic hierarchy.
Strictness margins, residual evidence, diagnostics, and package-owned solver
wrappers remain outside this slice.

The [SOS certificate map](/PD-LMI-package/documents/math/sos-certificates/)
explains how the implemented direct, Pólya, Putinar box, and full-box paths
relate to full-space SOS, general Putinar quadratic modules, Schmüdgen
preorderings, and the
one-dimensional Markov–Lukács theorem.
