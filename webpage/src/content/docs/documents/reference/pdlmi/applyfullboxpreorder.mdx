## Purpose

Create a new `pdlmi` that represents the stored residual with the implemented
cell-local full-box Bernstein-Gram preordering.

## Syntax

```matlab
Cbox = C.applyFullBoxPreorder()
Cbox = C.applyFullBoxPreorder(order)
Cbox = C.applyFullBoxPreorder(..., ValidationMode=mode)
```

## Description

The no-argument form selects the smallest admissible absolute order. The
explicit form selects `order`; it does not add `order` to the residual degree.
Both forms rebuild from `C.Residual` and `C.Relation`, return a new object, and
leave `C` unchanged. Reapplication therefore replaces an earlier full-box
order, a Pólya selection, or a Putinar selection instead of compounding it.

For a one-parameter residual of assembled degree $M$, the minimum is
$\lfloor M/2\rfloor$. Even-degree residuals use an unweighted Gram block plus
an $\alpha(1-\alpha)$-weighted block when that block has a nonempty basis.
Odd-degree residuals use separate $\alpha$- and
$(1-\alpha)$-weighted blocks.

For two or more parameters, the minimum is componentwise
$\lceil\mathbf M/2\rceil$. The
certificate contains one Gram term for every subset product of the box
generators $\alpha_s(1-\alpha_s)$. A term whose tensor Gram degree would have
a negative component is omitted.

For an entry-wise inequality, each MATLAB column-major scalar entry receives
an independent scalar certificate. Assembly creates independent Gram variables for every physical cell and every
active rate-vertex row. Each present Gram matrix is constrained positive
semidefinite, then exact identities match every Bernstein coefficient. For a
`<=` relation, the target coefficients are negated before positive-
semidefinite matching; for `>=`, the residual is matched directly. No implicit
positivity margin is added. The theoretical target is
$S^{(\mathbf c)}\succ0$; encode strictness in the residual with an explicit
$\varepsilon I$ margin before selecting this non-strict certificate.

For two parameters the four illustrated blocks correspond to the empty
subset, each single generator, and their product. In $\ell$ parameters the
same pattern has up to $2^\ell$ subset products. The
[SOS certificate chapter](/PD-LMI-package/documents/math/sos-certificates/)
develops the Gram and Markov–Lukács background step by step.

### Finite-SDP shape: two parameters, degree three

For one cell and one active rate row, let the sign-normalized residual have
Bernstein coefficients $C^{(\mathbf c)}[(i,k)]$ at tensor degree $(3,3)$. The default order
is $r=2$, so the residual is exactly elevated to degree $(4,4)$. The returned
constraint list has four PSD Gram constraints, followed by 25 exact affine
matrix equalities:

$$
\begin{aligned}
&Q_{\varnothing}\succeq0,\quad Q_{\{1\}}\succeq0,\\
&Q_{\{2\}}\succeq0,\quad Q_{\{1,2\}}\succeq0,\\
&\tilde C^{(\mathbf c)}[(p,q)]\\
&\quad=\mathcal A_{p,q}\bigl(\\
&\qquad Q_{\varnothing},Q_{\{1\}},\\
&\qquad Q_{\{2\}},Q_{\{1,2\}}\bigr),\\
&p,q=0,\ldots,4.
\end{aligned}
$$

Each $\mathcal A_{p,q}$ is a fixed affine Bernstein-coefficient map of the
Gram blocks. For instance,

$$
C^{(\mathbf c)}[(0,0)]=[Q_{\varnothing}]_{(0,0),(0,0)},
$$

while

$$
\begin{aligned}
&\tfrac14C^{(\mathbf c)}[(0,0)]
 +\tfrac34C^{(\mathbf c)}[(1,0)]\\
&=\tfrac12[Q_{\varnothing}]_{(0,0),(1,0)}\\
&\quad+\tfrac12[Q_{\varnothing}]_{(1,0),(0,0)}\\
&\quad+\tfrac14[Q_{\{1\}}]_{(0,0),(0,0)}.
\end{aligned}
$$

The detailed identity, basis degrees, and Gram dimensions are in the
[worked two-parameter example](/PD-LMI-package/documents/math/sos-certificates/#worked-full-box-example-two-parameters-degree-three).

## Arguments And Options

| Input | Description |
| :--- | :--- |
| `C` | Any `pdlmi` object. Its stored `Residual` and `Relation` are the source for the rebuilt certificate. |
| `order` | Optional finite nonnegative integer scalar shorthand or an $\ell$-element direction-wise absolute full-box order. It must meet the dimension-dependent minimum componentwise. |

## Returned Object

`Cbox` is a new `pdlmi` with `UsePolya=false`, `UsePutinar=false`,
`UseFullBoxPreorder=true`, and `FullBoxOrder` equal to the selected order.
Within each cell and rate row, `Constraints` stores all PSD Gram-block
conditions before the exact coefficient identities. `toYalmip(Cbox)` returns
those stored constraints in the same order.

## Deterministic Transcript Example

```matlab
yalmip('clear')
P = pdvar(1, {[0 1]}, Degree=2);
direct = P >= 0;
boxDefault = direct.applyFullBoxPreorder();
boxHigher = boxDefault.applyFullBoxPreorder(2);
polya = direct.applyPolya(1);
boxFromPolya = polya.applyFullBoxPreorder();
Fbox = toYalmip(boxDefault);

direct.UseFullBoxPreorder
direct.FullBoxOrder
numel(direct.Constraints)
boxDefault.UseFullBoxPreorder
boxDefault.FullBoxOrder
numel(boxDefault.Constraints)
boxHigher.FullBoxOrder
numel(boxHigher.Constraints)
boxFromPolya.UsePolya
boxFromPolya.UseFullBoxPreorder
boxFromPolya.FullBoxOrder
length(Fbox)
```

For the degree-two scalar residual, order one stores two PSD blocks followed by
three exact coefficient identities. Order two stores two PSD blocks followed
by five identities. The selection made from `polya` replaces Pólya assembly;
it does not use the already elevated constraints.

`ValidationMode` is transient, accepts case-insensitive `"fast"` or
`"strict"`, applies only to this rebuild, and is neither stored nor inherited.

## Validation And Errors

- A malformed `order` raises `pdlmi:InvalidFullBoxOrder`.
- A valid integer below the applicable minimum raises `pdlmi:FullBoxOrderTooLow`.
- Semidefinite and entry-wise inequalities retain their original global mode.
- Equality is direct-only; this method raises `pdlmi:UnsupportedEqualityCertificate` before validating `order`.
- Constructor selection errors are documented on the
  [`pdlmi constructor`](/PD-LMI-package/documents/reference/pdlmi/constructor/)
  page, including `pdlmi:InvalidUseFullBoxPreorder` and
  `pdlmi:ConflictingRelaxations`.

This method implements the fixed-order full-box preordering on each local
parameter box. In one parameter it shares the parity-specific Markov–Lukács
assembly with
[`applyPutinar`](/PD-LMI-package/documents/reference/pdlmi/applyputinar/).
For two or more parameters it is distinct because the full-box preordering includes every
generator-subset product. It is not a general-domain SOS interface, a
full-space SOS representation, or an automatic hierarchy selector.
