## How To Read This Page

`pdvar` stores affine YALMIP expressions at cell-local Bernstein labels. Each
cluster below puts the operation, runnable code, deterministic structural
output, and a visual explanation together. Symbolic coefficient names are
intentionally not promised: they depend on the active YALMIP workspace.

| Family | Operations |
| :--- | :--- |
| Affine algebra | `plus`, `minus`, `uplus`, `uminus` |
| Permitted products | `mtimes` with decision dependence on at most one side |
| Shape transforms | `transpose`, `ctranspose`, `reshape`, `squeeze`, `vec` |
| Matrix summaries | `diag`, `trace`, `sum`, `mean`, `cumsum`, `tril`, `triu` |
| Assembly and reordering | `cat`, `horzcat`, `vertcat`, `blkdiag`, `repmat`, `flip`, `fliplr`, `flipud`, `rot90` |
| Selection and inspection | `subsref`, `subsasgn`, `end`, `size`, `length`, `numel`, `ndims`, `height`, `width`, `isequal` |

## <span id="pdvar-plus"></span><span id="pdvar-minus"></span><span id="pdvar-uplus"></span><span id="pdvar-uminus"></span>Build Affine Sums And Differences

`plus`/`+` and `minus`/`-` combine affine expressions after compatible
grid/degree alignment. Numeric constants, affine `sdpvar`, and
coefficient-backed `pdmat` operands are promoted. `uplus` preserves the
expression; `uminus` negates every symbolic coefficient.

```matlab
yalmip('clear')
P = pdvar(1, {[0 1]});
Q = P - P;
R = P + 2;
S = -P;
fprintf('Q: decision=%d, degree=%d\n', Q.ContainsDecision, Q.Degree);
fprintf('R=%d-by-%d, S=%d-by-%d, uplus=%d-by-%d\n', ...
    size(R,1),size(R,2),size(S,1),size(S,2),size(+P,1),size(+P,2));
```

```text
Q: decision=0, degree=0
R=1-by-1, S=1-by-1, uplus=1-by-1
```

## <span id="pdvar-mtimes"></span>Multiply By Known Data

### Basic idea

`mtimes`/`*` is permitted when decision dependence occurs on at most one
converted operand. Numeric and coefficient-backed `pdmat` known data may
multiply a decision-dependent `pdvar` on a dimensionally valid side. An affine
`sdpvar` operand also carries decision dependence after conversion, so it may
multiply a `pdvar` only when that `pdvar` side has no decision dependence.
Products for which both converted operands have `ContainsDecision=true` are
nonlinear and rejected. Products with rate dependence on both sides are also
rejected.

### Formula

For a quadratic decision $P$ and affine known factor $A$ on one cell,

$$
(PA)[k]=\sum_{i+j=k}
\frac{\binom2i\binom1j}{\binom3k}P[i]A[j],
\qquad k=0,1,2,3.
$$

The written order is part of every term: $P[i]A[j]$ is not silently exchanged
with $A[j]P[i]$.

## <span id="pdvar-transpose"></span><span id="pdvar-ctranspose"></span><span id="pdvar-reshape"></span><span id="pdvar-squeeze"></span><span id="pdvar-vec"></span>Transpose And Reshape Symbolic Payloads

`transpose`/`.'` and `ctranspose`/`'` act on every symbolic coefficient
matrix. `reshape` preserves element count, `squeeze` removes singleton matrix
dimensions, and `vec` uses MATLAB column order. Rate and grid metadata remain
attached to the result.

```matlab
yalmip('clear')
P = pdvar(2, {[0 1]}, "symmetric");
Pt = P.'; Ph = P';
r = reshape(P,[1 4]); s = squeeze(P); v = vec(P);
fprintf('transpose=%d-by-%d, ctranspose=%d-by-%d\n', ...
    size(Pt,1),size(Pt,2),size(Ph,1),size(Ph,2));
fprintf('reshape=%d-by-%d, vec=%d-by-%d\n', ...
    size(r,1),size(r,2),size(v,1),size(v,2));
```

```text
transpose=2-by-2, ctranspose=2-by-2
reshape=1-by-4, vec=4-by-1
```

## <span id="pdvar-diag"></span><span id="pdvar-trace"></span><span id="pdvar-sum"></span><span id="pdvar-mean"></span><span id="pdvar-cumsum"></span><span id="pdvar-tril"></span><span id="pdvar-triu"></span>Extract And Reduce Matrix Structure

`diag(P,k)`, `tril(P,k)`, and `triu(P,k)` use MATLAB diagonal offsets.
`trace` reduces a square payload to a scalar. `sum`, `mean`, and `cumsum`
operate along matrix dimensions, not the Bernstein-label or physical-cell
axes.

```matlab
yalmip('clear')
P = pdvar(2, {[0 1]}, "symmetric");
D = diag(P); tr = trace(P); colsum = sum(P,1);
avg = mean(P,2); running = cumsum(P,2);
lo = tril(P); hi = triu(P);
fprintf('diag=%d-by-%d, trace=%d-by-%d, sum=%d-by-%d\n', ...
    size(D,1),size(D,2),size(tr,1),size(tr,2),size(colsum,1),size(colsum,2));
fprintf('mean=%d-by-%d, cumsum=%d-by-%d, triangles=%d-by-%d\n', ...
    size(avg,1),size(avg,2),size(running,1),size(running,2),size(lo,1),size(hi,2));
```

```text
diag=2-by-1, trace=1-by-1, sum=1-by-2
mean=2-by-1, cumsum=2-by-2, triangles=2-by-2
```

## <span id="pdvar-horzcat"></span><span id="pdvar-vertcat"></span><span id="pdvar-cat"></span><span id="pdvar-blkdiag"></span><span id="pdvar-repmat"></span>Assemble Symbolic Blocks

`horzcat`, `vertcat`, and `cat(dim,...)` concatenate compatible expressions.
`blkdiag` creates block-diagonal decision structures and `repmat` repeats a
payload. The package aligns compatible Bernstein metadata before assembling
each local symbolic matrix.

```matlab
yalmip('clear')
P = pdvar(1, {[0 1]});
H = [P P]; V = [P; P]; C = cat(2,P,P);
B = blkdiag(P,P); R = repmat(P,2,3);
fprintf('H=%d-by-%d, V=%d-by-%d, cat=%d-by-%d\n', ...
    size(H,1),size(H,2),size(V,1),size(V,2),size(C,1),size(C,2));
fprintf('blkdiag=%d-by-%d, repmat=%d-by-%d\n', ...
    size(B,1),size(B,2),size(R,1),size(R,2));
```

```text
H=1-by-2, V=2-by-1, cat=1-by-2
blkdiag=2-by-2, repmat=2-by-3
```

## <span id="pdvar-flip"></span><span id="pdvar-fliplr"></span><span id="pdvar-flipud"></span><span id="pdvar-rot90"></span>Reorder Matrix Entries

`flip(P,dim)`, `fliplr`, `flipud`, and `rot90(P,k)` reorder entries within
every symbolic coefficient matrix. They do not reverse a scheduling grid or
change local Bernstein labels.

```matlab
yalmip('clear')
P = pdvar([2 3], {[0 1]}, "full");
F = flip(P,2); L = fliplr(P); U = flipud(P); R = rot90(P);
fprintf('flip=%d-by-%d, fliplr=%d-by-%d, flipud=%d-by-%d\n', ...
    size(F,1),size(F,2),size(L,1),size(L,2),size(U,1),size(U,2));
fprintf('rot90=%d-by-%d\n', size(R,1),size(R,2));
```

```text
flip=2-by-3, fliplr=2-by-3, flipud=2-by-3
rot90=3-by-2
```

## <span id="pdvar-subsref"></span><span id="pdvar-subsasgn"></span><span id="pdvar-end"></span>Index And Assign Symbolic Blocks

Two-dimensional `subsref` selects a symbolic block from every local
coefficient. `subsasgn` accepts numeric or compatible decision blocks and
keeps grid/rate metadata. `end` resolves against matrix payload dimensions.

```matlab
yalmip('clear')
P = pdvar(2, {[0 1]}, "full");
entry = P(1,end);
P(2,1) = 0;
fprintf('entry=%d-by-%d, assigned=%d-by-%d\n', ...
    size(entry,1),size(entry,2),size(P,1),size(P,2));
```

```text
entry=1-by-1, assigned=2-by-2
```

## <span id="pdvar-size"></span><span id="pdvar-numel"></span><span id="pdvar-ndims"></span><span id="pdvar-length"></span><span id="pdvar-height"></span><span id="pdvar-width"></span><span id="pdvar-isequal"></span><span id="pdvar-disp"></span><span id="pdvar-display"></span><span id="pdvar-numArgumentsFromSubscript"></span>Inspect Shape, Equality, And Display

Shape methods report one symbolic matrix payload, not the number of physical
cells. `isequal` compares normalized metadata and symbolic coefficient
evidence. `disp`/`display` provide an object summary; `bernsteinTable` is the
coefficient-row diagnostic. `numArgumentsFromSubscript` keeps indexed results
scalar for MATLAB dot dispatch.

```matlab
yalmip('clear')
P = pdvar(2, {[0 1]}, "symmetric");
fprintf('size=%d-by-%d, length=%d, numel=%d, ndims=%d\n', ...
    height(P),width(P),length(P),numel(P),ndims(P));
fprintf('isequal(P,P)=%d\n', isequal(P,P));
```

```text
size=2-by-2, length=2, numel=4, ndims=2
isequal(P,P)=1
```


## Validation And Errors

- Products with decision dependence on both sides are rejected.
- Products with rate dependence on both sides are rejected.
- Numeric and coefficient-backed `pdmat` promotion still requires compatible
  physical bounds and matrix dimensions. Affine `sdpvar` multiplication is
  additionally limited to a `pdvar` operand without decision dependence.
- Matrix operations remain affine; this page does not introduce nonlinear
  decision products.
