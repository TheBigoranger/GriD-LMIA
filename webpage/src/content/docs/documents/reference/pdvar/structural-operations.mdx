Every operation acts on each symbolic coefficient matrix and returns an affine `pdvar`; cells, local labels, and rate metadata remain attached.

## <span id="pdvar-transpose"></span><span id="pdvar-ctranspose"></span><span id="pdvar-reshape"></span><span id="pdvar-squeeze"></span><span id="pdvar-vec"></span>Transpose and reshape

```matlab
yalmip('clear')
P = pdvar(2, {[0 1]}, "symmetric");
Pt = P.'; Ph = P'; r = reshape(P,[1 4]); s = squeeze(P); v = vec(P);
fprintf('transpose=%d-by-%d, ctranspose=%d-by-%d\n',size(Pt,1),size(Pt,2),size(Ph,1),size(Ph,2));
fprintf('reshape=%d-by-%d, vec=%d-by-%d\n',size(r,1),size(r,2),size(v,1),size(v,2));
```

```text
transpose=2-by-2, ctranspose=2-by-2
reshape=1-by-4, vec=4-by-1
```

## <span id="pdvar-diag"></span><span id="pdvar-trace"></span><span id="pdvar-sum"></span><span id="pdvar-mean"></span><span id="pdvar-cumsum"></span><span id="pdvar-tril"></span><span id="pdvar-triu"></span>Extract and reduce structure

`diag`, `tril`, and `triu` accept MATLAB diagonal offsets. `trace` requires square payloads. `sum`, `mean`, and `cumsum` operate on matrix dimensions, not storage axes.

```matlab
yalmip('clear')
P = pdvar(2, {[0 1]}, "symmetric");
D = diag(P); tr = trace(P); colsum = sum(P,1); avg = mean(P,2);
running = cumsum(P,2); lo = tril(P); hi = triu(P);
fprintf('diag=%d-by-%d, trace=%d-by-%d, sum=%d-by-%d\n',size(D,1),size(D,2),size(tr,1),size(tr,2),size(colsum,1),size(colsum,2));
fprintf('mean=%d-by-%d, cumsum=%d-by-%d, triangles=%d-by-%d\n',size(avg,1),size(avg,2),size(running,1),size(running,2),size(lo,1),size(hi,2));
```

```text
diag=2-by-1, trace=1-by-1, sum=1-by-2
mean=2-by-1, cumsum=2-by-2, triangles=2-by-2
```

## <span id="pdvar-horzcat"></span><span id="pdvar-vertcat"></span><span id="pdvar-cat"></span><span id="pdvar-blkdiag"></span><span id="pdvar-repmat"></span>Assemble symbolic blocks

```matlab
yalmip('clear')
P = pdvar(1, {[0 1]});
H = [P P]; V = [P; P]; C = cat(2,P,P); B = blkdiag(P,P); R = repmat(P,2,3);
fprintf('H=%d-by-%d, V=%d-by-%d, cat=%d-by-%d\n',size(H,1),size(H,2),size(V,1),size(V,2),size(C,1),size(C,2));
fprintf('blkdiag=%d-by-%d, repmat=%d-by-%d\n',size(B,1),size(B,2),size(R,1),size(R,2));
```

```text
H=1-by-2, V=2-by-1, cat=1-by-2
blkdiag=2-by-2, repmat=2-by-3
```

## <span id="pdvar-flip"></span><span id="pdvar-fliplr"></span><span id="pdvar-flipud"></span><span id="pdvar-rot90"></span>Reorder matrix entries

```matlab
yalmip('clear')
P = pdvar([2 3], {[0 1]}, "full");
F = flip(P,2); L = fliplr(P); U = flipud(P); R = rot90(P);
fprintf('flip=%d-by-%d, fliplr=%d-by-%d, flipud=%d-by-%d\n',size(F,1),size(F,2),size(L,1),size(L,2),size(U,1),size(U,2));
fprintf('rot90=%d-by-%d\n', size(R,1),size(R,2));
```

```text
flip=2-by-3, fliplr=2-by-3, flipud=2-by-3
rot90=3-by-2
```

## Validation and operation boundaries

Dimensions, offsets, repeat counts, and concatenation sizes must satisfy the corresponding MATLAB call. Compatible operands are aligned before assembly. These methods remain affine and never reorder the physical grid, local labels, or rate vertices.
