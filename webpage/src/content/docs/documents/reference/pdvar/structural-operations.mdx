The common mapping protocol lives in `pdbase`, but every method below is
public `pdvar` behavior. Each operation visits every symbolic coefficient and
every derivative rate row independently, returning an affine `pdvar` with
YALMIP variables, cells, labels, and rate metadata preserved.

## Transpose, reshape, squeeze, and vectorize

### <span id="pdvar-transpose"></span>`transpose` and <span id="pdvar-ctranspose"></span>`ctranspose`

```matlab
plain = P.'
conjugate = P'
```

Both swap symbolic payload dimensions. Only `ctranspose` conjugates.

### <span id="pdvar-reshape"></span>`reshape`

```matlab
out = reshape(P,rows,columns)
out = reshape(P,[rows columns])
out = reshape(P,[],columns)
```

Exactly two dimensions are supported. Element count must be preserved.
Failures use `pdvar:InvalidReshape`.

### <span id="pdvar-squeeze"></span>`squeeze`

```matlab
out = squeeze(P)
```

Applies squeeze coefficient-wise while preserving the always-two-dimensional
`MatrixSize`. Coefficient storage and rate rows remain separate from payload
dimensions.

### <span id="pdvar-vec"></span>`vec`

```matlab
out = vec(P)
```

Returns a column-major `numel(P) × 1` symbolic payload.

```matlab
yalmip('clear')
P = pdvar(2, {[0 1]}, "symmetric");
Pt = P.';
Ph = P';
r = reshape(P,[1 4]);
s = squeeze(P);
v = vec(P);
shapes = [size(Pt); size(Ph); size(r); size(s); size(v)]
```

```text
shapes =
     2     2
     2     2
     1     4
     2     2
     4     1
```

## Diagonal and reduction methods

### <span id="pdvar-diag"></span>`diag`

```matlab
out = diag(P)
out = diag(P,k)
```

Extracts or constructs symbolic diagonals. Empty or malformed offsets use
`pdvar:InvalidDiag`.

### <span id="pdvar-trace"></span>`trace`

```matlab
out = trace(P)
```

Sums the main diagonal of square, rectangular, row-vector, or column-vector
symbolic payloads. The result is `1 × 1`, and rectangular input is supported.

### <span id="pdvar-sum"></span>`sum` and <span id="pdvar-mean"></span>`mean`

```matlab
out = sum(P)
out = sum(P,dim)
out = sum(P,[dim1 dim2 ...])
out = sum(P,"all")

out = mean(P)
out = mean(P,dim)
out = mean(P,[dim1 dim2 ...])
out = mean(P,"all")
```

Dimension vectors are nonempty, unique, positive integers. Dimensions above
two are singleton identity operations. Data flags are unsupported. Errors use
`pdvar:InvalidSum` and `pdvar:InvalidMean`.

### <span id="pdvar-cumsum"></span>`cumsum`

```matlab
out = cumsum(P)
out = cumsum(P,dim)
out = cumsum(P,"forward")
out = cumsum(P,"reverse")
out = cumsum(P,dim,"forward")
out = cumsum(P,dim,"reverse")
```

Higher dimensions are singleton identity operations. Invalid directions and extra flags use
`pdvar:InvalidCumsum`.

### <span id="pdvar-tril"></span>`tril` and <span id="pdvar-triu"></span>`triu`

```matlab
lower = tril(P,k)
upper = triu(P,k)
```

`k` defaults to zero and must be a finite integer. Errors use
`pdvar:InvalidTriangularPart`.

```matlab
yalmip('clear')
P = pdvar([2 3], {[0 1]}, "full");
D = diag(P);
T = trace(P);
S = sum(P,[1 2]);
M = mean(P,1);
C = cumsum(P,2,"reverse");
shapes = [size(D); size(T); size(S); size(M); size(C)]
```

```text
shapes =
     2     1
     1     1
     1     1
     1     3
     2     3
```

## Concatenation and block assembly

### <span id="pdvar-horzcat"></span>`horzcat`, <span id="pdvar-vertcat"></span>`vertcat`, and <span id="pdvar-cat"></span>`cat`

```matlab
horizontal = [P Q]
vertical = [P; Q]
out = cat(1,P,Q)
out = cat(2,P,Q)
```

`pdvar` overrides direct-base concatenation. Compatible numeric, `sdpvar`,
`pdmat`, and `pdvar` operands are promoted and aligned. Only dimensions one
and two are supported. Ordinary/rate row structure and rate bounds must agree.
Errors use `pdvar:InvalidConcatenation` or
`pdvar:UnsupportedCatDimension`.

### <span id="pdvar-blkdiag"></span>`blkdiag`

```matlab
out = blkdiag(P,Q,...)
```

Builds a symbolic block diagonal through the same compatible promotion and
alignment rules.

### <span id="pdvar-repmat"></span>`repmat`

```matlab
out = repmat(P,n)
out = repmat(P,[rows columns])
out = repmat(P,rows,columns)
```

Uses positive integer two-dimensional repeats. Malformed forms raise
`pdvar:InvalidRepmat`.

```matlab
yalmip('clear')
P = pdvar(1, {[0 1]});
H = [P P];
V = [P; P];
C = cat(2,P,P);
B = blkdiag(P,P);
R = repmat(P,2,3);
shapes = [size(H); size(V); size(C); size(B); size(R)]
```

```text
shapes =
     1     2
     2     1
     1     2
     2     2
     2     3
```

## Flip and rotation

### <span id="pdvar-flip"></span>`flip`, <span id="pdvar-fliplr"></span>`fliplr`, and <span id="pdvar-flipud"></span>`flipud`

```matlab
out = flip(P)
out = flip(P,dim)
out = fliplr(P)
out = flipud(P)
```

`flip` defaults to the first nonsingleton payload dimension. Higher dimensions
are singleton identity operations. Invalid dimensions use `pdvar:InvalidFlip`.

### <span id="pdvar-rot90"></span>`rot90`

```matlab
out = rot90(P)
out = rot90(P,k)
```

Rotates each symbolic payload by a finite integer number of quarter turns.
Odd turns swap payload dimensions. Errors use `pdvar:InvalidRot90`.

```matlab
yalmip('clear')
P = pdvar([2 3], {[0 1]}, "full");
F = flip(P,2);
L = fliplr(P);
U = flipud(P);
R = rot90(P);
shapes = [size(F); size(L); size(U); size(R)]
```

```text
shapes =
     2     3
     2     3
     2     3
     3     2
```

## Limitations and See Also

These methods preserve affine decision dependence and operate on the symbolic
expressions before any `value` call,
`optimize`, or a solver. Physical cells, local labels, and rate vertices retain
their order.
