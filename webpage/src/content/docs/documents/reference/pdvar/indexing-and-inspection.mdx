## <span id="pdvar-subsref"></span>`subsref` and <span id="pdvar-end"></span>`end`

```matlab
block = P(rows,columns)
last = P(:,end)
property = P.Degree
```

Two-dimensional parentheses indexing selects the same symbolic block from
every local coefficient and derivative row. Subscripts may be `:`, matching
logical vectors, or finite in-range positive integers. `end` resolves against
the payload dimensions.

## <span id="pdvar-subsasgn"></span>`subsasgn`

```matlab
P(rows,columns) = numericValue
P(rows,columns) = compatibleDecisionOrKnownValue
```

Assignment accepts compatible numeric, affine `sdpvar`, `pdmat`, or `pdvar`
blocks and preserves grid, degree, ordinary/rate row structure, and rate
bounds. Dot and brace assignment are rejected with
`pdvar:UnsupportedAssignment`.

```matlab
yalmip('clear')
P = pdvar(2, {[0 1]}, "full");
entry = P(1,end);
P(2,1) = 0;
shapes = [size(entry); size(P)]
```

```text
shapes =
     1     1
     2     2
```

## Payload shape

### <span id="pdvar-size"></span>`size`

```matlab
shape = size(P)
[rows,columns] = size(P)
extent = size(P,dim)
```

### <span id="pdvar-numel"></span>`numel`, <span id="pdvar-ndims"></span>`ndims`, <span id="pdvar-length"></span>`length`, <span id="pdvar-height"></span>`height`, and <span id="pdvar-width"></span>`width`

```matlab
entryCount = numel(P)
dimensionCount = ndims(P)
largestExtent = length(P)
rows = height(P)
columns = width(P)
```

All report one always-two-dimensional symbolic payload. Cells, labels, and
rate rows have separate counts.

## <span id="pdvar-isequal"></span>`isequal`

```matlab
tf = isequal(P,Q)
```

Returns a MATLAB logical after comparing normalized grids, shapes, degree,
metadata, and symbolic coefficient evidence. Overloaded `P == Q` instead
creates a direct [`pdlmi` equality](/GriD-LMIA/documents/reference/pdvar/comparisons/#pdvar-comparison-eq).

```matlab
yalmip('clear')
P = pdvar(2, {[0 1]}, "symmetric");
shapeSummary = [height(P) width(P) length(P) numel(P) ndims(P)]
selfEqual = isequal(P,P)
```

```text
shapeSummary =
     2     2     2     4     2

selfEqual =
  logical
   1
```

## <span id="pdvar-disp"></span>`disp` and <span id="pdvar-display"></span>`display`

```matlab
disp(P)
P
```

Display prints a concise object summary. It does not promise workspace-dependent
YALMIP variable names; use
[`bernTable`](/GriD-LMIA/documents/reference/pdvar/berntable/)
for stable row-oriented diagnostics.

## <span id="pdvar-numArgumentsFromSubscript"></span>`numArgumentsFromSubscript`

The inherited MATLAB protocol returns one so an indexed `pdvar` stays a scalar
object for chained dot access. Users do not call it for modeling.

## Validation, limitations, and See Also

Malformed subscripts and incompatible assignments use `pdvar`-owned errors.
Indexing never selects cells, labels, or derivative rows and never calls
`value` or a solver.
