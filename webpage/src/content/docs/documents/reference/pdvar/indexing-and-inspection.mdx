## <span id="pdvar-subsref"></span><span id="pdvar-subsasgn"></span><span id="pdvar-end"></span>Index and assign symbolic blocks

```matlab
block = P(rows,cols); P(rows,cols) = value; last = P(:,end);
```

Two-dimensional `subsref` selects the same symbolic block from every local coefficient. `subsasgn` accepts numeric or compatible decision blocks and keeps grid/rate metadata. `end` resolves against payload dimensions. Dot access exposes properties and methods.

```matlab
yalmip('clear')
P = pdvar(2, {[0 1]}, "full");
entry = P(1,end); P(2,1) = 0;
fprintf('entry=%d-by-%d, assigned=%d-by-%d\n',size(entry,1),size(entry,2),size(P,1),size(P,2));
```

```text
entry=1-by-1, assigned=2-by-2
```

## <span id="pdvar-size"></span><span id="pdvar-numel"></span><span id="pdvar-ndims"></span><span id="pdvar-length"></span><span id="pdvar-height"></span><span id="pdvar-width"></span>Inspect payload shape

Shape methods report one symbolic matrix payload, not cells, local labels, or rate vertices.

## <span id="pdvar-isequal"></span>Structural versus modeling equality

`isequal(P,Q)` compares normalized metadata and symbolic coefficient evidence. It returns a MATLAB logical. Overloaded `P == Q` instead creates a direct [`pdlmi` modeling equality](/PD-LMI-package/documents/reference/pdvar/comparisons/#pdvar-comparison-eq).

```matlab
yalmip('clear')
P = pdvar(2, {[0 1]}, "symmetric");
fprintf('size=%d-by-%d, length=%d, numel=%d, ndims=%d\n',height(P),width(P),length(P),numel(P),ndims(P));
fprintf('isequal(P,P)=%d\n', isequal(P,P));
```

```text
size=2-by-2, length=2, numel=4, ndims=2
isequal(P,P)=1
```

## <span id="pdvar-disp"></span><span id="pdvar-display"></span><span id="pdvar-numArgumentsFromSubscript"></span>Display and dispatch

`disp` and `display` provide an object summary; `bernsteinTable` is the stable coefficient-row diagnostic. `numArgumentsFromSubscript` keeps indexed results scalar for MATLAB dot dispatch.

## Validation and operation boundaries

Indexing requires exactly two `:`, logical, or finite in-range positive-integer subscripts. Logical masks must match the indexed dimension. Assignments must preserve compatible matrix shape, grid, degree, and ordinary/derivative row structure. Display output does not promise YALMIP workspace-dependent variable names.
