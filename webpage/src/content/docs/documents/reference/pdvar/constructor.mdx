Cell indices, local coordinates, and modeled degree $m$ follow the
[global notation](/GriD-LMIA/documents/math/notation/#bernstein-labels-and-degrees).

The geometry and tensor Bernstein basis are identical to
[`pdmat Constructor`](/GriD-LMIA/documents/reference/pdmat/constructor/).
The difference is the payload: each local coefficient is a YALMIP decision
matrix or affine expression rather than a known numeric matrix. On cell
$\mathcal H_{\boldsymbol c}$, set

$$
\begin{aligned}
\mathcal I_{\boldsymbol m}
&:=\prod_{s=1}^{\ell}\{0,\ldots,m_s\},\\
\boldsymbol\alpha
&:=\phi_{\boldsymbol c}^{-1}(\boldsymbol\rho).
\end{aligned}
$$

The tensor-product basis and decision expansion are

$$
\begin{aligned}
B_{i_s}^{m_s}(\alpha_s)
&:=\binom{m_s}{i_s}
  \alpha_s^{i_s}(1-\alpha_s)^{m_s-i_s},\\
B_{\boldsymbol i}^{\boldsymbol m}(\boldsymbol\alpha)
&:=\prod_{s=1}^{\ell}B_{i_s}^{m_s}(\alpha_s).
\end{aligned}
$$

Therefore,

$$
\begin{aligned}
P^{(\boldsymbol c)}(\boldsymbol\rho)
&=\sum_{\boldsymbol i\in\mathcal I_{\boldsymbol m}}
  X^{(\boldsymbol c)}[\boldsymbol i]\,
  B_{\boldsymbol i}^{\boldsymbol m}(\boldsymbol\alpha).
\end{aligned}
$$

Here every $X^{(\boldsymbol c)}[\boldsymbol i]$ is stored in the corresponding
`LocalValues` leaf. On a shared face, adjacent continuous cells reference the
same YALMIP handles for every face label, so continuity is structural rather
than a separately assembled equality constraint.

## Purpose

Create a continuous cell-local Bernstein decision expression backed by YALMIP coefficients.

## Syntax

```matlab
P = pdvar(n, gridVectors)
P = pdvar(n, n, gridVectors)
P = pdvar(n, m, gridVectors)
P = pdvar(..., "full")
P = pdvar(..., "symmetric")
P = pdvar(..., Degree=0)
P = pdvar(..., Degree=degree, RateBounds=rb)
P = pdvar(..., ValidationMode=mode)
```

## Arguments And Options

| Input | Description |
| :--- | :--- |
| `n`, `m` | Positive integer matrix dimensions. `pdvar(n, gridVectors)` creates an `n x n` object, such as `pdvar(2,{[0 1]})`; `pdvar(n,m,gridVectors)` creates an `n x m` object, such as `pdvar(2,3,[0 1])`. |
| `gridVectors` | Numeric vector shorthand for one parameter, such as `[0 1 2]`, or a cell array of grid vectors, such as `{[0 1], [10 20]}`. |
| `"full"` | Use full YALMIP matrix coefficients, as in `pdvar(2,2,{[0 1]},"full")`. |
| `"symmetric"` | Use symmetric YALMIP matrix coefficients, as in `pdvar(2,{[0 1]},"symmetric")`. Requires square dimensions. |
| `Degree` | One finite nonnegative integer scalar shorthand or an $\ell$-element direction-wise vector. The default is `ones(1,ell)`; use an all-zero row for a parameter-independent decision. The accepted value is stored as a $1\times\ell$ row. |
| `RateBounds` | Finite $\ell\times2$ lower/upper rate-bound table stored as metadata, such as `RateBounds=[-1 1]` or `RateBounds=[-1 2; -3 4]`. |
| `ValidationMode` | Case-insensitive scalar text `"fast"` or `"strict"`; default `"fast"`, transient, and not stored. |

Unsupported public options: `IsContinuous`, `ContainsDecision`, and `HasRateDependence`.

## Returned Object

`P` is a parameter-dependent `pdvar < pdbase` object with
`ContainsDecision=true`. It is not one isolated `sdpvar` matrix. For the
default degree-1 constructor, each local grid cell stores the Bernstein
coefficient matrices that define `P(rho)` on that cell. The coefficient payloads
are YALMIP `sdpvar` matrices, and the cell-local storage lives in
`LocalValues`.

For one parameter segment, the scalar-entry mental model is:

$$
\begin{aligned}
\alpha
&:=\frac{\rho-\rho_1^{(c)}}
{\rho_1^{(c+1)}-\rho_1^{(c)}},\\
B_j^1(\alpha)&:=(1-\alpha)^{1-j}\alpha^j,\\
P^{(c)}(\rho)
&=B_0^1(\alpha)P^{(c)}[0]\\
&\quad+B_1^1(\alpha)P^{(c)}[1].
\end{aligned}
$$

Here $P^{(c)}[0]$ and $P^{(c)}[1]$ stand for YALMIP matrix coefficients. Adjacent
degree-1 cells share the boundary coefficient handle, so continuity is stored
directly in the coefficient graph instead of being enforced by a separate LMI
constraint. An all-zero degree reuses one symbolic coefficient over all
physical cells while still carrying grid metadata. A zero component on one
axis makes the decision constant in that direction; positive-degree axes
retain their control lattice and shared faces.

This is the standard forward-coordinate convention: `alpha=0` at the left
endpoint, so local label `0` selects $P^{(c)}[0]$; `alpha=1` at the right
endpoint, so local label `m` selects $P^{(c)}[m]$. At general degree $m$,
label $i$ selects $P^{(c)}[i]$ and uses
$B_i^m(\alpha)=\binom{m}{i}(1-\alpha)^{m-i}\alpha^i$.

In the stored object, each labeled endpoint is a YALMIP matrix coefficient.
For degree one, the stored leaves are
`LocalValues{1} = {P^(1)[0], P^(1)[1]}` and
`LocalValues{2} = {P^(2)[0], P^(2)[1]}`, with the shared-face handle satisfying
$P^{(1)}[1]=P^{(2)}[0]$.

The inherited fields are readable through dot syntax and have private set
access:

| Field | How to inspect it | Meaning for `pdvar` |
| :--- | :--- | :--- |
| `GridInfo` | `P.GridInfo.Vectors{1}`, `P.GridInfo.Points`, `P.GridInfo.Bounds` | Tensor-grid metadata inherited from `pdbase`. |
| `MatrixSize` | `P.MatrixSize` | Matrix size of each YALMIP coefficient payload. |
| `Degree` | `P.Degree` | Constructor-created objects accept every nonnegative direction-wise integer degree; algebra can also raise components. Stored as a $1\times\ell$ row. |
| `LocalValues` | `P.LocalValues{1}` or `P.coeffs(1)` | Cell-local YALMIP coefficient payloads. |
| `IsContinuous` | `P.IsContinuous` | `true` for constructor-created variables; `rhodiff` outputs are discontinuous. |
| `ContainsDecision` | `P.ContainsDecision` | `true` unless algebra proves a zero/nondecision result. |
| `HasRateDependence` | `P.HasRateDependence` | `true` when rate metadata or rate rows are present. |
| `RateBounds` | `P.RateBounds` | Empty or the $\ell\times2$ rate-bound table. |
| `SourceSummary` | `P.SourceSummary` | Source label such as `decision` or `derivative`. |

`pdvar` has no `FunctionHandle` field. Its internal values are symbolic
coefficient expressions in `LocalValues`. These fields are inspectable but not
assignable so that `Degree`, grid dimension, label order, continuity metadata,
and coefficient storage stay synchronized.

## Examples

### Default symmetric square variable

```matlab
yalmip('clear')
P = pdvar(2, {[0 1 2]}, "symmetric");
P.GridInfo.Vectors{1}
first = P.coeffs(1);
second = P.coeffs(2);
isequal(getvariables(first{2}), getvariables(second{1}))
P.MatrixSize
P.Degree
P.IsContinuous
P.ContainsDecision
P.SourceSummary
```

```text
ans =
     0     1     2

ans =
  logical
   1

ans =
     2     2

ans =
     1

ans =
  logical
   1

ans =
  logical
   1

ans =
    "decision"
```

### Rectangular full variable

```matlab
yalmip('clear')
Q = pdvar(2, 3, [0 1], "full", Degree=0);
Q.MatrixSize
Q.Degree
```

```text
ans =
     2     3

ans =
     0
```

### Rate metadata

```matlab
yalmip('clear')
P = pdvar(1, {[0 1], [10 20]}, RateBounds=[-1 2; -3 4]);
P.HasRateDependence
P.RateBounds
```

```text
ans =
  logical
   1

ans =
    -1     2
    -3     4
```

### Direction-wise degree and a constant axis

```matlab
yalmip('clear')
P = pdvar(1, {[0 1], [10 20]}, Degree=[2 0]);
P.Degree
P.ncoeff()
```

```text
ans =
     2     0

ans =
     3
```

The second zero component makes `P` constant along that parameter direction
while the first direction retains a quadratic control lattice.

## Validation And Errors

- Missing dimensions or grid vectors raise `pdvar:InvalidInput`.
- Invalid matrix dimensions raise `pdvar:InvalidMatrixSize`; malformed option
  sequences raise `pdvar:InvalidOptions`.
- Nonsquare `"symmetric"` variables raise `pdvar:InvalidStructure`.
- Negative, noninteger, nonfinite, malformed, or wrong-length constructor
  degrees raise `pdvar:InvalidDegree`.
- An explicit multidimensional scalar expands uniformly and warns
  `pdvar:ScalarDegreeExpansion`; omitted defaults and one-dimensional forms are
  silent.
- Invalid constructor rate metadata raises inherited `pdbase:InvalidRateBounds`.
- Invalid or missing validation values raise `pdvar:InvalidValidationMode`.
- Unknown options raise `pdvar:UnknownOption`; internal metadata options raise `pdvar:UnsupportedOption`.
