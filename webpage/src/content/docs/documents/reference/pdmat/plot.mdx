## Purpose

Sample a `pdmat` object through `evaluate` and plot each matrix entry over one or two selected parameter dimensions.

## Syntax

```matlab
h = plot(A)
h = plot(A, dims, Name, Value)
h = plot(A, SamplesPerCell=n)
```

## Arguments And Options

| Input | Description |
| :--- | :--- |
| `A` | A `pdmat` object. |
| `dims` | One or two positive parameter indices. Defaults to `1` for scalar objects and `[1 2]` for multi-parameter objects. |
| `SamplesPerCell` | Positive integer scalar. Default is `15`. |
| `Name, Value` | Additional plotting arguments passed to MATLAB `plot` or `surf`. |

## Output

`h` is a graphics object array, one entry per matrix payload element.

## Examples

### One-dimensional matrix entries

```matlab
A = pdmat({[-1 1]}, @(rho) [rho, rho.^2]);
h = plot(A, SamplesPerCell=80, LineWidth=2);
handleCount = numel(h)
sampleCount = numel(h(1).XData)
```

```text
handleCount =
     2

sampleCount =
    81
```

![One-dimensional pdmat plot showing rho and rho squared entries](/PD-LMI-package/plots/pdmat-plot-1d.png)

The linear and quadratic entries show that one graphics handle is returned for
each matrix payload entry.

### Two-dimensional surface

```matlab
A = pdmat({[-1 1], [0 2]}, ...
    @(rho1, rho2) 1 + rho1.^2 + 0.5*rho2 + rho1.*rho2);
h = plot(A, [1 2], SamplesPerCell=45, ...
    EdgeColor="none", FaceAlpha=0.78);
surfaceSize = size(h(1).XData)
faceAlpha = h(1).FaceAlpha
```

```text
surfaceSize =
    46    46

faceAlpha =
    0.7800
```

![Two-dimensional scalar pdmat surface over rho one and rho two](/PD-LMI-package/plots/pdmat-plot-2d.png)

The scalar surface includes both a quadratic term and a mixed term. `plot`
uses the selected grid axes as the two displayed dimensions.

### Three-parameter object, two-dimensional slice

`plot` accepts at most two selected dimensions. For a three-parameter object,
choose the two displayed axes; every unselected parameter is fixed at its
lower grid bound.

```matlab
A = pdmat({[-1 1], [0 2], [-2 3]}, ...
    @(rho1, rho2, rho3) [ ...
        1 + 0.4*rho1.^2 + 0.1*rho2 + 0.05*rho3, ...
        2 + 0.3*rho1 + 0.1*rho2 + 0.05*rho3; ...
        3 - 0.2*rho1 + 0.15*rho2 + 0.05*rho3, ...
        4 + 0.2*rho1.^2 + 0.25*rho2 + 0.05*rho3]);
h = plot(A, [1 2], SamplesPerCell=45, ...
    EdgeColor="none", FaceAlpha=0.55);
faceColors = [35 86 125; 103 127 145; 154 158 161; 205 205 205]/255;
for k = 1:numel(h)
    set(h(k), "FaceColor", faceColors(k,:));
end
legend(h, ["A(1,1)", "A(1,2)", "A(2,1)", "A(2,2)"], ...
    "Location", "eastoutside")
fixedThirdParameter = A.GridInfo.Bounds(3,1)
handleCount = numel(h)
```

```text
fixedThirdParameter =
    -2

handleCount =
     4
```

![Four vertically separated transparent entry surfaces from a two-by-two three-parameter pdmat object, with an outside legend and rho three fixed at its lower bound](/PD-LMI-package/plots/pdmat-plot-3d-slice.png)

This is a two-dimensional matrix slice, not a scalar or volume plot. The four
entry surfaces are vertically separated, use transparent fills, and keep their
legend outside the axes. The source explicitly selects dimensions `[1 2]`, so
the third coordinate remains fixed at its lower grid bound, $\rho_3=-2$.

## Validation And Errors

- Invalid `dims` raises `pdmat:InvalidPlotDimensions`.
- Invalid or missing `SamplesPerCell` raises `pdmat:InvalidPlotOptions`.

- Plotting is diagnostic and samples through `evaluate`.
- For higher-dimensional objects, unselected dimensions are fixed at their lower grid bounds.
