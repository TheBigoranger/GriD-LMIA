## Purpose

Sample a `pdmat` object through `evaluate` and plot each matrix entry over one or two selected parameter dimensions.

## Syntax

```matlab
h = plot(A)
h = plot(A, SamplesPerCell=n)
h = plot(A, dims, SamplesPerCell=n)
h = plot(A, ..., RateVertex=k)
h = plot(A, ..., Name, Value)
```

## Arguments And Options

| Input | Description |
| :--- | :--- |
| `A` | A `pdmat` object. |
| `dims` | One or two positive parameter indices. Defaults to `1` for scalar objects and `[1 2]` for multi-parameter objects. |
| `SamplesPerCell` | Positive integer scalar. Default is `15`. |
| `RateVertex` | One-based stored rate row. Rate-row objects default to row one. ordinary data reject this option. |
| `Name, Value` | Additional plotting arguments passed to MATLAB `plot` or `surf`. |

## Output

`h` is a graphics object array, one entry per matrix payload element.

For explicit rate rows, select the stored vertex inside the plotting call:

```matlab
A = pdmat([0 1], {0, 2}, Degree=1, RateBounds=[-1 2]);
D = rhodiff(A);
plot(D, RateVertex=2, SamplesPerCell=20, LineWidth=2);
```

## Examples

### One-dimensional matrix entries

```matlab
A = pdmat({[-1 1]}, @(rho) [rho, rho.^2]);
h = plot(A, SamplesPerCell=80, LineWidth=2);
handleCount = numel(h)
sampleCount = numel(h(1).XData)
```

```text
handleCount =
     2

sampleCount =
    81
```

![One-dimensional pdmat plot showing rho and rho squared entries](/GriD-LMIA/plots/pdmat-plot-1d.png)

The linear and quadratic entries show that one graphics handle is returned for
each matrix payload entry.

### Two-dimensional surface

```matlab
A = pdmat({[-1 1], [0 2]}, ...
    @(rho1, rho2) 1 + rho1.^2 + 0.5*rho2 + rho1.*rho2);
h = plot(A, [1 2], SamplesPerCell=45, ...
    EdgeColor="none", FaceAlpha=0.78);
surfaceSize = size(h(1).XData)
faceAlpha = h(1).FaceAlpha
```

```text
surfaceSize =
    46    46

faceAlpha =
    0.7800
```

![Two-dimensional scalar pdmat surface over rho one and rho two](/GriD-LMIA/plots/pdmat-plot-2d.png)

The scalar surface includes both a quadratic term and a mixed term. `plot`
uses the selected grid axes as the two displayed dimensions.

### Two-dimensional matrix-valued surface

```matlab
A = pdmat({[-1 1], [0 2]}, @(rho1, rho2) [ ...
    1 + 0.8*rho1 + 0.25*rho2; ...
    1 - 0.8*rho1 + 0.25*rho2]);
h = plot(A, [1 2], SamplesPerCell=45, ...
    EdgeColor="none", FaceAlpha=0.62);
set(h(1), "FaceColor", [35 86 125]/255)
set(h(2), "FaceColor", [0.55 0.55 0.55])
legend(h, ["A(1,1)", "A(2,1)"], ...
    "Location", "eastoutside")
crossValue = A.evaluate([0 1]);
leftValue = A.evaluate([-1 1]);
rightValue = A.evaluate([1 1]);
crossingError = abs(crossValue(1) - crossValue(2))
ordering = [leftValue(1) < leftValue(2), ...
    rightValue(1) > rightValue(2)]
handleCount = numel(h)
```

```text
crossingError =
     0

ordering =
  1×2 logical array
   1   1

handleCount =
     2
```

![Two intersecting entry surfaces from a two-by-one two-parameter pdmat object, with an outside legend](/GriD-LMIA/plots/pdmat-plot-2d-matrix.png)

The two entries are equal for every $\rho_2$ along $\rho_1=0$. Their ordering
reverses on opposite sides: the first entry is lower for $\rho_1<0$ and higher
for $\rho_1>0$. The intersection is therefore part of the represented matrix
function in place of a visual offset. The legend stays outside the axes and
keeps both surfaces visible.

## Validation And Errors

- Invalid `dims` raises `pdmat:InvalidPlotDimensions`.
- Invalid or missing `SamplesPerCell` raises `pdmat:InvalidPlotOptions`.
- Supplying `RateVertex` for ordinary data or selecting beyond the stored
  rows raises `pdmat:InvalidRateVertex`.

- Plotting is diagnostic and samples through `evaluate`.
- For higher-dimensional objects, unselected dimensions are fixed at their lower grid bounds.
