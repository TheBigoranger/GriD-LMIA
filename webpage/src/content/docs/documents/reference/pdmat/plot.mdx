## Purpose

Sample a `pdmat` object through `evaluate` and plot each matrix entry over one or two selected parameter dimensions.

## Syntax

```matlab
h = plot(A)
h = plot(A, dims, Name, Value)
h = plot(A, SamplesPerCell=n)
```

## Arguments And Options

| Input | Description |
| :--- | :--- |
| `A` | A `pdmat` object. |
| `dims` | One or two positive parameter indices. Defaults to `1` for scalar objects and `[1 2]` for multi-parameter objects. |
| `SamplesPerCell` | Positive integer scalar. Default is `15`. |
| `Name, Value` | Additional plotting arguments passed to MATLAB `plot` or `surf`. |

## Output

`h` is a graphics object array, one entry per matrix payload element.

## Examples

### One-dimensional crossing higher-order data

```matlab
A = pdmat({[-1 1]}, @(rho) [ ...
    0.4 + 0.9*rho - 0.8*rho.^2 + 0.5*rho.^3, ...
   -0.2 + 0.3*rho + 1.1*rho.^2 - 0.7*rho.^3 + 0.2*rho.^4]);
h = plot(A, SamplesPerCell=80, LineWidth=2);
handleCount = numel(h)
sampleCount = numel(h(1).XData)
```

```text
handleCount =
     2

sampleCount =
    81
```

![One-dimensional pdmat plot showing rho and rho squared entries](/PD-LMI-package/plots/pdmat-plot-1d.png)

The two cubic/quartic entries cross on $[-1,1]$, making entry identity and nonlinear sampling visible.

### Two-dimensional surface

```matlab
A = pdmat({[-1 1], [-1 1]}, @(rho, eta) [ ...
    0.5 + 0.7*rho - 0.6*eta + 0.9*rho.*eta + ...
        0.4*rho.^2 - 0.3*eta.^3 + 0.25*rho.^2.*eta.^2, ...
    0.2 - 0.5*rho + 0.8*eta - 0.7*rho.*eta - ...
        0.3*rho.^2 + 0.35*eta.^2 + 0.3*rho.^3.*eta]);
h = plot(A, [1 2], SamplesPerCell=45, ...
    EdgeColor="none", FaceAlpha=0.72);
surfaceSize = size(h(1).XData)
faceAlpha = h(1).FaceAlpha
```

```text
surfaceSize =
    46    46

faceAlpha =
    0.7200
```

![Two-dimensional pdmat surface plot showing two matrix entries over rho one and rho two](/PD-LMI-package/plots/pdmat-plot-2d.png)

The two higher-order surfaces include mixed terms and intersect on the physical box. `plot` creates one graphics object per matrix payload entry.

## Validation And Errors

- Invalid `dims` raises `pdmat:InvalidPlotDimensions`.
- Invalid or missing `SamplesPerCell` raises `pdmat:InvalidPlotOptions`.

- Plotting is diagnostic and samples through `evaluate`.
- For higher-dimensional objects, unselected dimensions are fixed at their lower grid bounds.
