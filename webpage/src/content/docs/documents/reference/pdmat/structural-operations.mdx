Every method applies the matching MATLAB matrix operation to each stored coefficient payload and returns a `pdmat` with the same physical-cell tree.

## <span id="pdmat-transpose"></span><span id="pdmat-ctranspose"></span><span id="pdmat-reshape"></span><span id="pdmat-squeeze"></span><span id="pdmat-vec"></span>Transpose and reshape

```matlab
At = A.'; Ah = A'; R = reshape(A,[m n]); S = squeeze(A); V = vec(A);
```

`reshape` preserves payload element count, `squeeze` removes singleton dimensions, and `vec` uses MATLAB column-major order. For real coefficients, transpose and conjugate transpose have the same numeric effect.

```matlab
A = pdmat({[0 1]}, {[1 2; 3 4], [5 6; 7 8]}, Degree=1);
At = A.'; r = reshape(A,[1 4]); s = squeeze(A); v = vec(A);
fprintf('transpose=%d-by-%d, reshape=%d-by-%d, vec=%d-by-%d\n', ...
    size(At,1),size(At,2),size(r,1),size(r,2),size(v,1),size(v,2));
disp(v.evaluate(0))
```

```text
transpose=2-by-2, reshape=1-by-4, vec=4-by-1
     1
     3
     2
     4
```

## <span id="pdmat-diag"></span><span id="pdmat-trace"></span><span id="pdmat-sum"></span><span id="pdmat-mean"></span><span id="pdmat-cumsum"></span><span id="pdmat-tril"></span><span id="pdmat-triu"></span>Extract, reduce, and triangularize

`diag(A,k)`, `tril(A,k)`, and `triu(A,k)` accept MATLAB diagonal offsets. `trace` requires square payloads. `sum`, `mean`, and `cumsum` operate along a matrix dimension, never along cell or Bernstein-label axes.

```matlab
A = pdmat({[0 1]}, {[1 2; 3 4], [5 6; 7 8]}, Degree=1);
D = diag(A); tr = trace(A); colsum = sum(A,1);
avg = mean(A,2); running = cumsum(A,2); lo = tril(A); hi = triu(A);
disp(D.evaluate(0)); fprintf('trace=%g\n', tr.evaluate(0));
disp(colsum.evaluate(0)); disp(lo.evaluate(0)+hi.evaluate(0)-diag(diag(A.evaluate(0))))
```

```text
     1
     4
trace=5
     4     6
     1     2
     3     4
```

## <span id="pdmat-horzcat"></span><span id="pdmat-vertcat"></span><span id="pdmat-cat"></span><span id="pdmat-blkdiag"></span><span id="pdmat-repmat"></span>Assemble larger matrices

```matlab
A = pdmat({[0 1]}, {1, 2}, Degree=1);
H = [A A]; V = [A; A]; C = cat(2,A,A); B = blkdiag(A,A); R = repmat(A,2,3);
fprintf('H=%d-by-%d, V=%d-by-%d, cat=%d-by-%d\n',size(H,1),size(H,2),size(V,1),size(V,2),size(C,1),size(C,2));
fprintf('blkdiag=%d-by-%d, repmat=%d-by-%d\n',size(B,1),size(B,2),size(R,1),size(R,2));
```

```text
H=1-by-2, V=2-by-1, cat=1-by-2
blkdiag=2-by-2, repmat=2-by-3
```

disp(fliplr(A).evaluate(0)); disp(flipud(A).evaluate(0)); disp(rot90(A).evaluate(0))

## Validation and operation boundaries

Matrix dimensions, offsets, repeat counts, and concatenation sizes must satisfy the corresponding MATLAB operation. Function-only objects without coefficient evidence are rejected by coefficient structural operations. No method reorders physical cells or local labels.
