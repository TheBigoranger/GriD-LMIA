These methods are implemented by `pdbase` unless noted, but each is public
`pdmat` behavior. Every successful operation maps known coefficient matrices
and returns a `pdmat` with its cells, labels, degree, source metadata, and
numeric payload type preserved.

## Transpose, reshape, squeeze, and vectorize

### <span id="pdmat-transpose"></span>`transpose` and <span id="pdmat-ctranspose"></span>`ctranspose`

```matlab
plain = A.'
conjugate = A'
```

Both swap payload rows and columns; only `ctranspose` conjugates.

### <span id="pdmat-reshape"></span>`reshape`

```matlab
out = reshape(A,rows,columns)
out = reshape(A,[rows columns])
out = reshape(A,[],columns)
```

Exactly two dimensions are supported. At most one may be inferred with `[]`,
and the element count must be preserved. Invalid calls raise
`pdmat:InvalidReshape`.

### <span id="pdmat-squeeze"></span>`squeeze`

```matlab
out = squeeze(A)
```

Applies MATLAB `squeeze` coefficient-wise, then preserves the package's
always-two-dimensional payload contract. It never creates an N-D `pdmat`.

### <span id="pdmat-vec"></span>`vec`

```matlab
out = vec(A)
```

Returns a `numel(A) × 1` known-data payload in MATLAB column-major order.

```matlab
A = pdmat({[0 1]}, {[1 2; 3 4], [5 6; 7 8]}, Degree=1);
At = A.';
r = reshape(A,[1 4]);
s = squeeze(A);
v = vec(A);
shapes = [size(At); size(r); size(s); size(v)]
vAtZero = v.evaluate(0)
```

```text
shapes =
     2     2
     1     4
     2     2
     4     1

vAtZero =
     1
     3
     2
     4
```

## Diagonal and reduction methods

### <span id="pdmat-diag"></span>`diag`

```matlab
out = diag(A)
out = diag(A,k)
```

Extracts diagonal `k` from matrix coefficients or builds a diagonal matrix
from vector coefficients. Empty-diagonal offsets and malformed offsets raise
`pdmat:InvalidDiag`.

### <span id="pdmat-trace"></span>`trace`

```matlab
out = trace(A)
```

Sums the main diagonal and returns `1 × 1` known data. Rectangular matrices
and row/column vectors are supported; square input is not required.

### <span id="pdmat-sum"></span>`sum` and <span id="pdmat-mean"></span>`mean`

```matlab
out = sum(A)
out = sum(A,dim)
out = sum(A,[dim1 dim2 ...])
out = sum(A,"all")

out = mean(A)
out = mean(A,dim)
out = mean(A,[dim1 dim2 ...])
out = mean(A,"all")
```

Dimensions must be a nonempty unique positive-integer vector. Dimensions above
two are singleton no-ops. `"native"`, `"omitmissing"`, and other data flags
are unsupported. Errors use `pdmat:InvalidSum` or `pdmat:InvalidMean`.

### <span id="pdmat-cumsum"></span>`cumsum`

```matlab
out = cumsum(A)
out = cumsum(A,dim)
out = cumsum(A,"forward")
out = cumsum(A,"reverse")
out = cumsum(A,dim,"forward")
out = cumsum(A,dim,"reverse")
```

A lone direction uses the first nonsingleton matrix dimension. Higher
dimensions are singleton no-ops. Invalid dimensions, directions, or extra
flags raise `pdmat:InvalidCumsum`.

### <span id="pdmat-tril"></span>`tril` and <span id="pdmat-triu"></span>`triu`

```matlab
lower = tril(A)
lower = tril(A,k)
upper = triu(A)
upper = triu(A,k)
```

The optional diagonal offset is a finite integer scalar. Errors use
`pdmat:InvalidTriangularPart`.

```matlab
A = pdmat({[0 1]}, {[1 2 3; 4 5 6], [2 4 6; 8 10 12]}, Degree=1);
diagonalAtZero = diag(A).evaluate(0)
rectangularTrace = trace(A).evaluate(0)
allSum = sum(A,[1 2 3]).evaluate(0)
columnMeans = mean(A,1).evaluate(0)
reverseRows = cumsum(A,2,"reverse").evaluate(0)
```

```text
diagonalAtZero =
     1
     5

rectangularTrace =
     6

allSum =
    21

columnMeans =
    2.5000    3.5000    4.5000

reverseRows =
     6     5     3
    15    11     6
```

## Concatenation and block assembly

### <span id="pdmat-horzcat"></span>`horzcat`, <span id="pdmat-vertcat"></span>`vertcat`, and <span id="pdmat-cat"></span>`cat`

```matlab
horizontal = [A B]
vertical = [A; B]
out = cat(1,A,B)
out = cat(2,A,B)
```

Unlike direct `pdbase` values, `pdmat` implements coefficient-wise
concatenation. Inputs may include compatible numeric matrices or `pdmat`
values. The method aligns physical grids and degrees, preserves matrix-block
order, and supports only dimensions one and two. Errors use
`pdmat:InvalidConcatenation` or `pdmat:UnsupportedCatDimension`.

### <span id="pdmat-blkdiag"></span>`blkdiag`

```matlab
out = blkdiag(A,B,...)
```

Builds a block diagonal after compatible known-data promotion and alignment.
At least one input must be `pdmat`; malformed calls use
`pdmat:InvalidBlkdiag`.

### <span id="pdmat-repmat"></span>`repmat`

```matlab
out = repmat(A,n)
out = repmat(A,[rows columns])
out = repmat(A,rows,columns)
```

Uses positive integer two-dimensional repeat counts. Invalid forms use
`pdmat:InvalidRepmat`.

```matlab
A = pdmat({[0 1]}, {1, 2}, Degree=1);
H = [A A];
V = [A; A];
C = cat(2,A,A);
B = blkdiag(A,A);
R = repmat(A,2,3);
shapes = [size(H); size(V); size(C); size(B); size(R)]
```

```text
shapes =
     1     2
     2     1
     1     2
     2     2
     2     3
```

## Flip and rotation

### <span id="pdmat-flip"></span>`flip`, <span id="pdmat-fliplr"></span>`fliplr`, and <span id="pdmat-flipud"></span>`flipud`

```matlab
out = flip(A)
out = flip(A,dim)
out = fliplr(A)
out = flipud(A)
```

`flip` defaults to the first nonsingleton payload dimension. An explicit
dimension is a positive integer; higher dimensions are no-ops. Invalid calls
use `pdmat:InvalidFlip`.

### <span id="pdmat-rot90"></span>`rot90`

```matlab
out = rot90(A)
out = rot90(A,k)
```

Rotates each payload by `k` quarter turns; `k` is a finite integer and odd
turns swap the payload dimensions. Errors use `pdmat:InvalidRot90`.

```matlab
A = pdmat({[0 1]}, {[1 2; 3 4], [5 6; 7 8]}, Degree=1);
leftRight = fliplr(A).evaluate(0)
upDown = flipud(A).evaluate(0)
quarterTurn = rot90(A).evaluate(0)
```

```text
leftRight =
     2     1
     4     3

upDown =
     3     4
     1     2

quarterTurn =
     2     4
     1     3
```

## Limitations and See Also

Function-only data without stored Bernstein evidence raises
`pdmat:FunctionOnlyAlgebra`. Structural operations do not sample such a
function, call YALMIP, modify the physical grid, or change local-label/rate
ordering.
