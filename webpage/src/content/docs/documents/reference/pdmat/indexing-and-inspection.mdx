## <span id="pdmat-subsref"></span><span id="pdmat-subsasgn"></span><span id="pdmat-end"></span>Index and assign blocks

```matlab
block = A(rows,cols); A(rows,cols) = value; last = A(:,end);
```

Parentheses index the two matrix-payload dimensions coefficient by coefficient. Assignment accepts numeric or compatible `pdmat` blocks and preserves the grid contract. `end` resolves against payload dimensions, not cell count. Dot access remains property or method access.

```matlab
A = pdmat({[0 1]}, {[1 2; 3 4], [5 6; 7 8]}, Degree=1);
entry = A(1,end);
A(2,1) = pdmat({[0 1]}, {9,10}, Degree=1);
fprintf('entry=%d-by-%d\n', size(entry,1), size(entry,2));
disp(A.evaluate(1))
```

```text
entry=1-by-1
     5     6
    10     8
```

## <span id="pdmat-size"></span><span id="pdmat-numel"></span><span id="pdmat-ndims"></span><span id="pdmat-length"></span><span id="pdmat-height"></span><span id="pdmat-width"></span>Inspect payload shape

`size`, `length`, `numel`, `ndims`, `height`, and `width` report the matrix payload shape at one parameter location. Use `ncell` and `ncoeff` for storage counts.

## <span id="pdmat-isequal"></span>Structural equality

`isequal(A,B)` compares normalized grid metadata, payload shape, and coefficient evidence. It is a MATLAB predicate, not a modeling constraint.

```matlab
A = pdmat({[0 1]}, {[1 2; 3 4], [5 6; 7 8]}, Degree=1);
fprintf('size=%d-by-%d, length=%d, numel=%d, ndims=%d\n', ...
    height(A),width(A),length(A),numel(A),ndims(A));
fprintf('isequal(A,A)=%d\n', isequal(A,A));
```

```text
size=2-by-2, length=2, numel=4, ndims=2
isequal(A,A)=1
```

## <span id="pdmat-disp"></span><span id="pdmat-display"></span><span id="pdmat-numArgumentsFromSubscript"></span>Display and dispatch

`disp` and `display` print the object summary; `bernsteinTable` is the coefficient-row diagnostic. `numArgumentsFromSubscript` keeps indexed results scalar for MATLAB dot dispatch.

## Validation and operation boundaries

Indexing requires exactly two `:`, logical, or finite in-range positive-integer subscripts. Logical masks must match their dimension. Assignments must have compatible shape and parameter metadata. Shape methods describe payloads only.
