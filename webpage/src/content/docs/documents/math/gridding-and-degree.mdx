The physical grid and the local Bernstein degree are independent modeling
choices.

## The Two Independent Choices

For scheduling axis $s$, define the ordered grid

$$
\begin{aligned}
\mathcal G_s&=\{\rho_s^{(1)},\ldots,\rho_s^{(k_s)}\},\\
\mathcal G&=\mathcal G_1\times\cdots\times\mathcal G_\ell.
\end{aligned}
$$

The one-based symbol $\rho_s^{(j)}$ denotes physical node $j$ on axis
$s$, while $k_s$ is that axis's node count. The tensor grid exactly
partitions the parameter box
$\mathcal P=\prod_s[\underline\rho_s,\overline\rho_s]$ into
$\prod_s(k_s-1)$ physical cells.

The one-based physical cell index
$\vect c=(c_1,\ldots,c_\ell)$ selects

$$
\begin{aligned}
\mathcal H_{\vect c}
&=\prod_{s=1}^{\ell}
[\rho_s^{(c_s)},\rho_s^{(c_s+1)}],\\
h_s^{\vect c}
&=\rho_s^{(c_s+1)}-\rho_s^{(c_s)}.
\end{aligned}
$$

The grid determines where cells begin and end. The decision degree $\vect m$
determines how many Bernstein labels live inside each cell. Refining
$\mathcal G_s$ changes the physical partition while preserving $\vect m$.
Raising one component of $\vect m$ changes the local decision space while
preserving the physical cells.

## One-Dimensional Input

For $\mathcal G_1=\{0,0.5,1\}$, there are two cells. The physical map
$\phi_{\vect c}:[0,1]^\ell\to\mathcal H_{\vect c}$ and its inverse are

$$
\begin{aligned}
\rho_s
&=\phi_{\vect c,s}(\vect\alpha),\\
\rho_s
&=\rho_s^{(c_s)}+h_s^{\vect c}\alpha_s,\\
\vect\alpha
&=\phi_{\vect c}^{-1}(\vect\rho),\\
\alpha_s
&=\frac{\rho_s-\rho_s^{(c_s)}}{h_s^{\vect c}}
\in[0,1].
\end{aligned}
$$

Consequently,

$$
\frac{\partial}{\partial\rho_s}
=\frac{1}{h_s^{\vect c}}
\frac{\partial}{\partial\alpha_s}.
$$

For one-parameter degree $\vect m=(2)$, each cell has labels
$i_1=0,1,2$, but a continuous
`pdvar` shares the endpoint handle across the interface.

## Two-Dimensional Input

An anisotropic grid is valid and often useful:

```matlab
grid = {[0 0.25 1], [-1 1]};
A = pdmat(grid, @(rho1,rho2) [1+rho1 rho1*rho2; rho1*rho2 2+rho2^2], ...
    Degree=[3 1]);
```

The first axis has two physical intervals and the second has one. Every cell
still uses local coordinates
$\vect\alpha=(\alpha_1,\alpha_2)\in[0,1]^2$.
For direction-wise degree $\vect m=(3,1)$, each local coefficient array has
$\prod_s(m_s+1)=8$ labels $\vect i=(i_1,i_2)$. This anisotropic choice
allows a cubic first-parameter dependence and only a linear second-parameter
dependence inside each cell.

## The ℓ-Dimensional Case

The number of physical cells is
$\prod_{s=1}^{\ell}(k_s-1)$. For direction-wise degree
$\vect m=(m_1,\ldots,m_\ell)$, each cell has
$\prod_s(m_s+1)$ local labels. A scalar input is uniform shorthand for this
row vector. The two products measure different things:
physical partition size and local polynomial representation size.

`pdbase.cells()` traverses physical cells, while `pdbase.labels()` traverses
zero-based Bernstein labels. `LocalValues` stores the corresponding nested
cell structure. See [pdbase storage and inspection](/GriD-LMIA/documents/reference/pdbase/storage-inspection/)
for the exact traversal contract.

## Distinct Grid, Degree, And Certificate Controls

- Grid refinement changes the physical partition and may localize
  conservatism.
- Degree elevation changes only the Bernstein representation of the same
  polynomial.
- Increasing one or more components of decision degree $\vect m$ enlarges
  the decision-function family in those directions.
- Increasing residual degree $\vect M$ can result from products and
  componentwise common-degree alignment even when $\vect m$ is unchanged.
- Increasing Pólya increment $\vect d$ or Gram order $\vect r$ changes the
  selected finite certificate. SparsePutinar `CliqueSize` value $b$ and
  SparseFullBox window side $w$ change their respective tensor-window supports.

## Limitations

The implemented geometry is a tensor-product box grid. Grid knots must be
ordered and cell widths must be positive. The implemented partition is a
caller-specified tensor grid. Discontinuous coefficient-backed `pdmat` data are
supported, while the shared-face continuity argument applies to continuous
decisions.
