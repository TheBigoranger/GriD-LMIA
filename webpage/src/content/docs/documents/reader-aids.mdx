## Task To API

| Task | Primary API | Result |
|---|---|---|
| Represent known parameter data | [`pdmat`](/GriD-LMIA/documents/reference/pdmat/) | Numeric matrix function with function or Bernstein evidence |
| Create a decision function | [`pdvar`](/GriD-LMIA/documents/reference/pdvar/) | Affine YALMIP coefficient expression on a tensor grid |
| Add scheduling-rate vertices | [`rhodiff`](/GriD-LMIA/documents/reference/pdvar/rhodiff/) | One derivative row for each distinct rate-box vertex |
| Form an equality or inequality | [`pdlmi`](/GriD-LMIA/documents/reference/pdlmi/) | Stored residual with a selected finite certificate |
| Select a finite certificate | [certificate methods](/GriD-LMIA/documents/reference/pdlmi/#api-usepolya) | Rebuilt value object with Direct, Pólya, Putinar, SparsePutinar, SparseFullBox, or FullBox state |
| Export solver constraints | [`toYalmip`](/GriD-LMIA/documents/reference/pdlmi/toyalmip/) | YALMIP constraint array |
| Inspect normalized metadata | [`pdbase`](/GriD-LMIA/documents/reference/pdbase/) | Grid, degree, storage, continuity, decision, and rate metadata |
| Validate package setup | [`install_pd_lmi`](/GriD-LMIA/documents/getting-started/installation/) | Installation report and verified MATLAB path setup |

| Family | Known data | Affine decision data | Rate rows | Returned object |
|---|---:|---:|---:|---|
| `pdbase` inspection and storage | Yes | Yes | Yes | `pdbase` family value or MATLAB metadata |
| `pdmat` coefficient algebra | Yes | — | Yes | `pdmat` |
| `pdvar` affine algebra | Yes | Yes | Yes | `pdvar` |
| `pdvar` comparisons | Yes | Yes | Yes | `pdlmi` |
| `pdlmi` certificate selection | Residual evidence | Affine residual | Independent rows | `pdlmi` |
| `pdlmi.toYalmip` | Residual evidence | Affine residual | Independent rows | YALMIP `constraint` |

Decision dependence remains affine. Supported products contain decision
dependence on one operand. Equality uses direct coefficient identities.

## Certificate Selection

| Method | Main control | Matrix positivity representation | Useful starting point |
|---|---|---|---|
| Direct | Bernstein degree and grid | Coefficientwise semidefinite tests | Low cost and transparent coefficient evidence |
| Pólya | Degree-elevation increment | Elevated coefficientwise tests | Direct leaves inconclusive coefficient evidence |
| Putinar | Absolute Gram order | Singleton-generator Gram module | Moderate dimension and fixed-order Gram certificate |
| SparsePutinar | Window side and absolute order | Overlapping local Gram blocks | Smaller maximum Gram blocks with more blocks |
| SparseFullBox | Window side and absolute order | Windowed square-free generator products | Local preordering blocks |
| FullBox | Absolute Gram order | Complete square-free generator products | Canonical dense endpoint |

Grid refinement changes physical cells. Bernstein degree changes the local
decision space. Degree elevation preserves the represented polynomial. A Pólya
increment raises coefficient-test degree. Gram order controls basis size.
Window or clique size controls local block extent. Rate-vertex reduction is exact
for affine rate dependence and stores one row per distinct vertex.
