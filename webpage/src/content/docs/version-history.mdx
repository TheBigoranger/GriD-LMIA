## Version History

Documentation v1.1.2 is the current manual snapshot. The latest tagged GitHub
Release remains v1.1.0. No v1.1.2 tag or GitHub Release exists. Earlier rows
retain the final patch release from each completed minor line; a commit suffix
identifies historical release evidence.

## Update Rule

<ul>
  <li>Version source of truth: <code>{historyPolicy.sourceOfTruth}</code>.</li>

Keep the documentation snapshot and latest Release as distinct rows whenever
their versions differ. When a later tagged patch becomes the final release of
an older minor line, replace that line's retained row in
`webpage/src/data/version-history.js`. Keep the displayed current-version
number synchronized from the TeX manual rather than editing generated version
data manually.
