## Version History

Documentation v1.5.2 is the current manual snapshot and latest tagged GitHub
Release. The preceding tagged Release is v1.5.1. Source and documentation
snapshots are identified separately. Release links identify tags, while commit
links identify published snapshots.
The current catalog contains five public examples. Earlier entries retain their
historical scope and validation results.

## Update Rule

<ul>
  <li>Version source of truth: <code>{historyPolicy.sourceOfTruth}</code>.</li>
  <li>Current-version sync: {historyPolicy.updateRule}</li>
  <li>History append rule: {historyPolicy.appendRule}</li>

Keep the documentation snapshot and latest Release as distinct rows whenever
their versions differ. When a later tagged patch becomes the final release of
an older minor line, replace that line's retained row in
`webpage/src/data/version-history.js`. Keep the displayed current-version
number synchronized from the TeX manual. The build generates the displayed data.
