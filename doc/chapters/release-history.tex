The entries below follow the version metadata and dated release commits kept
in the project history.

  Restructured the printable manual into chapter files, unified the TeX and Web

  Published the expanded manual and interactive Web guide.  Released by commit
  \code{75d70dc}.

  Recorded by commit \code{2d420cc}.

  Added the Putinar certificate manual coverage.  Released by commit
  \code{d896146}.

  \item[v0.3.2 --- July 14, 2026]
  Published the synchronized PD-LMI manual and Web guide.  Released by commit
  \code{eb5ac24}.

  \item[v0.3.1 --- July 14, 2026]
  Expanded the manual and renamed the plotting assets from the earlier
  \code{dpmat} spelling to \code{pdmat}.  Released by commit \code{aa71a2a}.

  \item[v0.3.0 --- July 13, 2026]
  Published the first synchronized printable manual and Web reference.
  Released by commit \code{7fc820f}.

  \code{b1e0d51}.

  \item[v0.1.0 --- July 3, 2026]
  Introduced the \code{pdbase} foundation and the first package manual.
  Released by commit \code{63c06ee}.
