\chapter*{Version History}
\addcontentsline{toc}{chapter}{Version History}

The entries below distinguish the current documentation snapshot from tagged GitHub Releases and retain the latest release from each completed minor line.

\begin{description}[
  style=nextline, leftmargin=1.5em, labelindent=0pt, labelwidth=1em, labelsep=0.5em, itemindent=0pt, font=\normalfont\bfseries]
  \item[v1.1.6 documentation --- July 28, 2026] Unifies tensor-grid, cell, Bernstein-degree, residual, target, and Gram notation across the printable and Web manuals; states SparseFullBox directly through the paper notation \(Q_J^{(w)}\) for symmetric block-band Gram matrices of bandwidth \(w\); expands the Bernstein convolution and Gram/SOS foundations; adds the Math Concepts navigation and interactive \code{pdmat} addition, multiplication, and elevation explorers; and fits the Welcome three-dimensional grid at every supported rotation. The MATLAB API is unchanged. No tag or GitHub Release is created; v1.1.0 remains the latest tagged release.

  \item[v1.1.0 --- July 26, 2026 --- latest GitHub Release] Documents the centralized \code{pdbase} ownership of shared matrix protocols and transformations while retaining complete \code{pdmat}/\code{pdvar} discoverability, reclassifies three object-aware backend utilities out of the six-function \code{+helper} namespace, and adds complete SparseFullBox constructor, state, certificate, endpoint, validation, and mathematical coverage. It adds no solver wrapper, hidden margin, or runtime API beyond the current source.

  \item[v1.0.0 --- July 19, 2026] Marks the first stable public release of the documented package workflow. It consolidates installation and test-suite verification, the \code{pdbase}/\code{pdmat}/\code{pdvar}/\code{pdlmi} object model, continuous arbitrary-degree decision storage and rate-vertex differentiation, MATLAB-style matrix operations and indexing, and direct, P\'olya, Putinar, and full-box finite certificate assembly. The 1.0 documentation also makes the affine-expression, tensor-box, certificate-sufficiency, and solver-ownership boundaries explicit; this milestone does not add new runtime behavior beyond the implementation covered by the current code and tests.

  \item[v0.4.7 --- July 18, 2026] Completed the v0.4 manual and Web explorer refresh around the LPV-to-cellwise-Bernstein-to-solver workflow, including installer guidance, the public API reference, mathematical cross-references, and storage-transformation examples. Released by commit \code{c6a2e25}.

  \item[v0.3.6 --- July 16, 2026] Completed the public rename to \code{pdbase}/\code{pdmat}/\code{pdvar}/\code{pdlmi}, corrected forward Bernstein coordinates, added FullBox and Putinar certificates with independent SOS validation, hardened API boundaries, and defined entry-wise inequality behavior. Released by commit \code{fe74a65}.

  \item[v0.2.12 --- July 13, 2026] Completed the \code{pdmat}/\code{pdvar}/\code{pdlmi} layers, rate-aware differentiation, display, plotting, structural algebra, direct finite assembly, P\'olya selection, and deterministic reference examples and tests. Released by commit \code{98b63e5}.

  \item[v0.1.0 --- July 3, 2026] Introduced the original grid-and-storage foundation and the first package manual, including Bernstein traversal, validation, and helper contracts. Released by commit \code{63c06ee}.
\end{description}
