\chapter*{Version History}
\addcontentsline{toc}{chapter}{Version History}

The entries below identify the current source and documentation snapshot, the latest tagged GitHub Release, and the final documentation snapshot or latest release from each completed minor line.

\begin{description}[
  style=nextline, leftmargin=1.5em, labelindent=0pt, labelwidth=1em, labelsep=0.5em, itemindent=0pt, itemsep=0pt, parsep=0pt, topsep=0pt, partopsep=0pt, font=\normalfont\bfseries]
  \item[v1.4.0 --- August 14, 2026 --- latest tagged GitHub Release] Adds dimension-compatible multiplication between a real affine two-dimensional \code{sdpvar} and coefficient-backed \code{pdmat} in either order. The mixed product returns \code{pdvar}, supports scalar broadcasting and rectangular matrices, and preserves the known grid, degree, continuity, rate metadata, active known-data rate rows, and existing YALMIP variables. The public inventory remains unchanged at 192 symbols, and the existing \termdef{psd} certificate families are unchanged. Ordinary \code{RateBounds} with zero stored rows is now treated as metadata instead of active rate dependence. The synchronized printable and Web manuals document the accepted and rejected product boundaries.
  \item[v1.3.8 documentation --- August 10, 2026 --- final v1.3 documentation snapshot] Consolidates the v1.3 public API around \code{bernTable}, \code{elevate}, and the \code{use*} certificate selectors, explains the reusable elevation, product, Direct, P\'olya, and Bernstein--Gram plans, and documents the SparsePutinar and SparseFullBox tensor-window constructions. It also repairs printable and Web layout at narrow or page-boundary conditions and aligns both mathematical appendices with the main manual style. This final v1.3 snapshot retains the source-indexed 192-symbol public API and solver-status boundaries.

  \item[v1.2.4 documentation --- August 5, 2026 --- final v1.2 documentation snapshot] Adds the SparsePutinar tensor-window certificate to the public API and documents its overlapping-window coefficient accumulation, canonical endpoints, validation rules, and relationship to dense Putinar and SparseFullBox. It also expands the \termdef{sos} and Gram background and adds the software-paper citation. This documentation-only snapshot remains outside the tagged GitHub Releases.

  \item[v1.1.6 documentation --- July 28, 2026 --- final v1.1 snapshot] Unifies tensor-grid, cell, Bernstein-degree, residual, target, and Gram notation across the printable and Web manuals. It also expands the Bernstein convolution and Gram/SOS foundations, adds the Math Concepts navigation and interactive \code{pdmat} addition, multiplication, and elevation explorers, and fits the Welcome three-dimensional grid at every supported rotation. The MATLAB API is unchanged.

  \item[v1.0.0 --- July 19, 2026] Marks the first stable public release of the documented package workflow. It consolidates installation and test-suite verification, the \code{pdbase}/\code{pdmat}/\code{pdvar}/\code{pdlmi} object model, continuous arbitrary-degree decision storage and rate-vertex differentiation, MATLAB-style matrix operations and indexing, and direct, P\'olya, Putinar, and full-box finite certificate assembly. The 1.0 documentation also makes the affine-expression, tensor-box, certificate-sufficiency, and solver-ownership boundaries explicit. Runtime behavior remains the implementation covered by the current code and tests.

  \item[v0.4.7 --- July 18, 2026] Completed the v0.4 manual and Web explorer refresh around the LPV-to-cell-wise-Bernstein-to-solver workflow, including installer guidance, the public API reference, mathematical cross-references, and storage-transformation examples. Released by commit \code{c6a2e25}.

  \item[v0.3.6 --- July 16, 2026] Completed the public rename to \code{pdbase}/\code{pdmat}/\code{pdvar}/\code{pdlmi}, corrected forward Bernstein coordinates, added FullBox and Putinar certificates with independent SOS validation, hardened API boundaries, and defined entry-wise inequality behavior. Released by commit \code{fe74a65}.

  \item[v0.2.12 --- July 13, 2026] Completed the \code{pdmat}/\code{pdvar}/\code{pdlmi} layers, rate-aware differentiation, display, plotting, structural algebra, direct finite assembly, P\'olya selection, and deterministic reference examples and tests. Released by commit \code{98b63e5}.

  \item[v0.1.0 --- July 3, 2026] Introduced the original grid-and-storage foundation and the first package manual, including Bernstein traversal, validation, and helper contracts. Released by commit \code{63c06ee}.
\end{description}
