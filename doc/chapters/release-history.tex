The entries below follow the version metadata and dated release commits kept in the project history.

\begin{description}[
  style=nextline, leftmargin=1.5em, labelindent=0pt, labelwidth=1em, labelsep=0.5em, itemindent=0pt, font=\normalfont\bfseries] \item[v0.4.6 --- July 18, 2026] Consolidates the v0.4 release line: split and reorganized the manual around the LPV-to-cellwise-Bernstein-to-solver workflow, completed the installer guidance, compressed the opening workflow chapter, and refreshed the visual and API reference. This release also adds targeted links to the mathematical appendices, restores the opening equation references, moves index terms to their defining pages, supplies missing example separators, and completes two storage-transformation examples covering whole-object elevation and protected grid-and-degree alignment through public algebra.

  \item[v0.3.6 --- July 16, 2026] Completed the public rename to \code{pdbase}/\code{pdmat}/\code{pdvar}/\code{pdlmi}, corrected forward Bernstein coordinates, added Full Box and Putinar certificates with independent SOS validation, hardened API boundaries, and defined entry-wise inequality behavior. Released by commit \code{fe74a65}.

  \item[v0.2.12 --- July 13, 2026] Completed the \code{pdmat}/\code{pdvar}/\code{pdlmi} layers, rate-aware differentiation, display, plotting, structural algebra, direct finite assembly, P\'olya selection, and deterministic reference examples and tests. Released by commit \code{98b63e5}.

  \item[v0.1.0 --- July 3, 2026] Introduced the original grid-and-storage foundation and the first package manual, including Bernstein traversal, validation, and helper contracts. Released by commit \code{63c06ee}.
\end{description}
