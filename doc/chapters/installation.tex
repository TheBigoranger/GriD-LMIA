\section{One-Call Installation}
\index{installation}\index{path conflict}\index{YALMIP dependency}
\label{sec:installation}

Start \matlab{} in the downloaded repository and run command \code{install_pd_lmi} once. The installer adds only the repository root to the end of the MATLAB path. MATLAB resolves the package's class, package, and private directories from that root. Dependency installation and \code{startup.m} configuration remain user-managed operations.

\begin{lstlisting}[style=dpmatlab]
report = install_pd_lmi();
\end{lstlisting}

The returned structure records the package root, the YALMIP root discovered on the current MATLAB path, the working \termdef{sdp} solver, the paths added by this run, and whether the path was persisted:

\begin{lstlisting}[style=dpsyntax]
report.PackageRoot
report.YALMIPRoot
report.Solver
report.AddedPaths
report.Persisted
\end{lstlisting}

YALMIP must already be on the active MATLAB path. The installer validates \code{yalmip}, \code{sdpvar}, \code{sdpsettings}, \code{optimize}, and \code{getavailablesolvers}. It then probes available SDP solvers in the fixed commercial-first order MOSEK, COPT, SeDuMi, SDPT3, and LMILAB using a tiny bounded SDP. A failed probe falls through to the next candidate. If any precondition, shadow check, solver probe, or path persistence operation fails, the installer restores the original MATLAB path and stops with one of these stable errors:

\begin{lstlisting}[style=dpsyntax]
install_pd_lmi:MissingYALMIP
install_pd_lmi:IncompleteYALMIP
install_pd_lmi:NoWorkingSDPSolver
install_pd_lmi:PathConflict
install_pd_lmi:PathSaveFailed
\end{lstlisting}

Repeated successful calls are idempotent. When the repository root is already present, the installer preserves the single path entry and returns an empty \code{AddedPaths}.

\section{Validate the Installation}
\index{validation}\index{solver probe}
\label{sec:verification}

After the installer has selected and recorded a working solver, run the current MATLAB test entry point from the repository root:

\begin{lstlisting}[style=dpmatlab]
results = tests.run_all();
\end{lstlisting}

The entry point covers installer rollback and persistence behavior, helper utilities, \code{pdbase}, \code{pdmat}, \code{pdvar}, and \code{pdlmi}. YALMIP-backed tests and the solver smoke tests use the same automatic commercial-first solver policy as the installer. Their diagnostics identify the actual solver used.

\section{Run a Minimal Solver Example}
\label{sec:quick-start}

The installer already rejects shadowed package classes before it persists the path. To inspect the selected solver and exercise the solver-facing assembly boundary, use the report together with a small known-data example:

\begin{lstlisting}[style=dpmatlab]
report.Solver
A = pdmat({[0 1]}, {1, 3}, Degree=1);
T = bernTable(A, "oneLine");
disp(T)
\end{lstlisting}

\begin{lstlisting}[style=dpoutput]
    CellSubscript          Expression
    _____________    _______________________

        {[1]}        "(1-alpha)*1 + alpha*3"
\end{lstlisting}

\begin{lstlisting}[style=dpmatlab]
yalmip('clear')
P = pdvar(2, {[0 1]}, "symmetric", Degree=4);
C = P >= 0;
F = toYalmip(C);
Cputinar = C.usePutinar();
Fputinar = toYalmip(Cputinar);
CspPutinar = C.useSpPut(2);
FspPutinar = toYalmip(CspPutinar);
sparsePutinarState = [CspPutinar.UseSparsePutinar, ...
    CspPutinar.SparsePutinarOrder, CspPutinar.CliqueSize, ...
    numel(CspPutinar.Constraints)]
Csp = C.useSpBox(2);
Fsp = toYalmip(Csp);
Cbox = C.useFullBox();
Fbox = toYalmip(Cbox);
\end{lstlisting}

\begin{lstlisting}[style=dpoutput]
sparsePutinarState = 1x4 double
     1     2     2     8
\end{lstlisting}

\code{F} is the direct coefficient certificate. For the same stored residual, \code{Fputinar} is dense Putinar, \code{FspPutinar} is clique-size-two SparsePutinar, \code{Fsp} is width-two SparseFullBox, and \code{Fbox} is FullBox. Any one can be passed to ordinary YALMIP calls. Use the selected solver from the report when an explicit solver setting is useful:

\begin{lstlisting}[style=dpsyntax]
opts = sdpsettings('solver', report.Solver, 'verbose', 0);
sol = optimize(F, [], opts);
\end{lstlisting}
